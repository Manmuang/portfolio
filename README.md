# พอร์ตโฟลิโอ ณัฐพงษ์ ขวัญชัย

- เว็บ: หน้าแรกสั้น (`/`) + หน้ารายละเอียด 3 โปรเจกต์ (`/projects/*`) ที่ต้องกดเข้าไปดูเอง
- เรซูเม่ A4 หน้าเดียว (`/resume` → `public/resume.pdf`)

เนื้อหาทั้งหมดอยู่ที่เดียว: [`src/content/data.ts`](src/content/data.ts)
สร้างด้วย Next.js (static export) + TypeScript + Tailwind 4 ฟอนต์ Noto Sans Thai

## คำสั่ง

```bash
npm run dev      # เปิดเว็บเพื่อแก้
npm run build    # สร้างเว็บแบบ static ไว้ที่ out/
npm run pdf      # สร้างเรซูเม่ A4 จาก out/ (ต้อง build ก่อน)
```

`npm run pdf -- --shot` บันทึกภาพเรซูเม่ไว้ตรวจที่ `private/resume.png`
ถ้าเนื้อหายาวเกิน 1 หน้า สคริปต์จะหยุดและบอกว่าล้นกี่ px ให้ตัดเนื้อหา

## สิ่งที่ต้องกรอกก่อนเผยแพร่

- รูปถ่าย: วางไฟล์ที่ `public/photo.jpg` (หรือ .png) แล้ว build ใหม่ ถ้าไม่มี เรซูเม่จะแสดงกรอบอักษร "ณ" แทน
- ช่องทางติดต่อ (อีเมล โทร LINE GitHub LinkedIn) ใน `profile.contact` ช่องที่ว่างจะไม่แสดงบนหน้า
- หนังสือรับรองการฝึกงาน: ไม่ได้ฝังในเว็บหรือเรซูเม่ ให้แนบไฟล์ต้นฉบับแยกตอนสมัครงาน

## ไฟล์ที่ไม่ควรเผยแพร่

`private/` (รวม `cert.png`) และ `notes/` อยู่ใน `.gitignore` แล้ว `notes/` มีรายละเอียดภายในที่ใช้เขียนเนื้อหา

## กติกาของเนื้อหา

- หน้าแรกต้องอ่านจบใน 1–2 นาที เรื่องลึกอยู่ในหน้า `/projects/*`
- ตัวเลขทุกตัวต้องมาจากที่นับหรืออ่านได้จริง ห้ามประมาณ
- เรียกลูกค้าแบบทั่วไปเท่านั้น ห้ามใส่ชื่อลูกค้า ชื่อแบรนด์ เลขบิล หรือข้อมูลจริง
- ห้ามเปิดเผยรายละเอียดช่องโหว่ของระบบเดิม
- ขออนุญาตบิ๊กสาระก่อนเผยแพร่ แล้วค่อยเปลี่ยนชื่อทั่วไปเป็นชื่อจริงได้
